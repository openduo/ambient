# The whole runtime for this service. There is no deep learning framework here:
# an ONNX graph, a Kaldi feature extractor, and numpy.
#
# onnxruntime-gpu carries both the CUDA and the CPU execution provider, so one
# wheel serves both values of SPK_DEVICE. On a machine with no NVIDIA driver,
# install plain `onnxruntime` of the same version instead and set SPK_DEVICE=cpu;
# nothing else changes.
#
# These are the versions this service was measured on. Newer ONNX Runtime
# releases are expected to work, but the execution providers are where this
# model's vectors diverge (see embed_server.py), so a version bump can move the
# embedding space without changing its name. Re-run smoke.sh after one, and
# compare its printed vector against the previous build before trusting a room's
# existing anchors.
onnxruntime-gpu==1.23.2
kaldi-native-fbank==1.22.3
numpy>=1.24
